pinyu-stats プライバシーポリシー

pinyu-stats は、運営者が自分の YouTube チャンネルの数字を振り返るために、自分の PC で動かすツールです。運営者以外の人は使いません。

読み取るデータ

YouTube Data API と YouTube Analytics API を使い、運営者自身のチャンネルの動画一覧と、再生回数・視聴時間などの統計を読み取ります。読み取りだけで、動画の投稿・編集・削除はしません。

使い道と保存場所

読み取ったデータと認証情報は、運営者の PC にだけ保存し、動画の振り返りにだけ使います。第三者への提供・販売・外部への送信はしません。

アクセスの取り消し

Google アカウントのサードパーティのアクセスのページから、いつでもこのツールのアクセスを取り消せます。

YouTube API サービス

このツールは YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーも適用されます。
